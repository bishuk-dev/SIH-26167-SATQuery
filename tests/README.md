# Tests

The test tree mirrors SatQuery's externally meaningful behavior:

- `ingestion/` — safe file inspection and observation creation.
- `geo/` — deterministic coordinate, overlap, alignment, and measurement behavior.
- `routing/` — intent, feasibility, and workflow selection.
- `evidence/` — evidence contracts, provenance, and geometry.
- `verification/` — PASS/WARN/FAIL policy behavior.
- `models/` — inference adapters and frozen model regressions.
- `integration/` — cross-boundary API and workflow tests.
