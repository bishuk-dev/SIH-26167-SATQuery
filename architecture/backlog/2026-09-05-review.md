## 2. Sensor domain module (`satquery/sensors/`)

**Status:** ACCEPT FOR LATER, targeted

After Phase 4D freezes, consider centralizing stable sensor semantics:

- Sentinel-1 polarization vocabulary (`S1_BANDS = ("VV", "VH")`)
- Sentinel-2 band identities (`S2_BANDS`)
- native band resolutions (`S2_RESOLUTION`)

**Constraints:**

- Do NOT move dataset-specific constants such as BigEarthNet pair counts into the sensor layer.
- Do NOT merge model-specific BIFOLD channel order/normalization into generic sensor definitions.
- Start with band lists and resolution only; defer CRS, calibration coefficients, metadata schema to a second pass.
